# 1. Record architecture decisions

Date: 2026-09-26

## Status

Accepted

## Context

Decisions in this project should be easy to follow later, also for people who were not part of them.

## Decision

Important decisions are written down as short ADRs in `docs/adr/`, in the format of [Michael Nygard](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).

## Consequences

- Each ADR has a number and is never deleted. A changed decision gets a new ADR that replaces the old one.
- ADRs stay short: context, decision, consequences.
